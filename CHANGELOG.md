## 0.0.1-dev

* Initial development release of the Wultra Mobile Token SDK for Flutter.
* Operation management: list, detail, claim, approve, reject, and history.
* Pre-approval screens with multi-screen flow support (including legacy format backward compatibility).
* Post-approval screens (Review, Redirect, Generic).
* Mobile Token Data builder and pre-approval screen recorder.
* QR operation offline authorization.
* Push notification registration.
* Inbox message management.
* Proximity check (TOTP) support.
